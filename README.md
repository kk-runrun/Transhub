# 智能翻译工作台

这是一个为跨境电商产品文案工作者设计的一站式 AI 批量翻译与质检工具。通过本工具，你可以利用大语言模型的能力，结合自定义知识库，实现高质量、专业化的批量文件翻译。

## ✨ 主要功能

- **多格式支持**: 支持上传 `.docx` (Word), `.xlsx` (Excel), `.txt` (文本) 文件进行翻译。
- **知识库集成 (RAG)**: 上传产品手册、术语表等作为背景知识，让 AI 的翻译更贴近你的业务需求，减少术语错误。
- **双路翻译对比**: AI 会同时生成“精准直译”和“流畅意译”两个版本，并给出推荐，方便你选择最佳结果。
- **AI 自动评审**: AI 会自动对比两个翻译版本，选出更优的一个并说明理由，帮你快速决策。
- **人工审核与 QA**: 在最终交付前，你可以在线编辑和优化译文，并提交给 AI 进行最终的质量检查 (QA)。
- **一键下载**: 完成后的译文可以方便地下载为 `.docx` 或 `.txt` 文件。

## 🌊 工作流程是怎样的？

整个过程被设计成一个自动化的流水线，你的操作非常简单：

1.  **配置**: 在左侧边栏填入你的 API Key 和模型信息。
2.  **输入**:
    - **(可选)** 上传知识库文件（如 PDF, Word），AI 会先学习这些内容。
    - 上传你需要翻译的一个或多个文件。
3.  **执行**: 点击“开始批量翻译”按钮。
4.  **AI 处理**: 程序会自动在后台完成以下步骤：
    - **读取与分片**: 读取文件内容，并将其切分成适合处理的小块。
    - **检索增强 (RAG)**: 对每一块内容，从你上传的知识库中寻找最相关的背景信息。
    - **双路翻译**: 将原文和背景信息一起发给 AI，生成“精准”和“流畅”两个版本。
    - **AI 评审**: AI 对比两个版本，选出最优版本作为默认的最终译文。
5.  **人工审核**:
    - 你可以在界面上看到 AI 推荐的版本和理由。
    - 你可以在编辑框里对译文进行任何修改。
    - 修改满意后，可以点击“提交 AI 质检”，让 AI 做最后的检查。
6.  **完成与下载**:
    - QA 通过后，文件状态变为“已完成”。
    - 你可以随时下载最终确认的译文。

## 🚀 快速上手指南

你只需要有 Python 环境，不需要任何编程基础。下面是 Windows 和 macOS 的详细步骤。

### 准备工作：安装 Python

如果你的电脑还没有 Python，请先安装它。

- **Windows**: 前往 [Python 官网](https://www.python.org/downloads/) 下载最新稳定版的安装包，安装时务必勾选 **"Add Python to PATH"** 选项。
- **macOS**: 系统通常自带 Python。你可以打开“终端” (Terminal) 输入 `python3 --version` 来检查。如果没有，可以从 [Python 官网](https://www.python.org/downloads/macos/) 下载安装。

---

### Windows 用户

1.  **下载代码**:
    - 下载本项目所有文件，解压后放在一个你找得到的位置（例如桌面）。

2.  **打开命令提示符 (CMD)**:
    - 在文件资源管理器中，进入你解压后的项目文件夹。
    - 在地址栏输入 `cmd` 然后按回车，会弹出一个黑色窗口。

3.  **创建并激活虚拟环境** (推荐，避免库冲突):
    ```bash
    # 创建一个名为 venv 的虚拟环境
    python -m venv venv

    # 激活虚拟环境
    .\venv\Scripts\activate
    ```
    *成功后，你会在命令行前面看到 `(venv)` 字样。*

4.  **安装依赖库**:
    ```bash
    pip install -r requirements.txt
    ```
    *这个命令会自动安装所有需要的工具包，请耐心等待。*

5.  **运行程序**:
    ```bash
    streamlit run app.py
    ```
    *运行后，会自动在你的浏览器中打开一个网页，这就是程序界面。*

---

### macOS 用户

1.  **下载代码**:
    - 下载本项目所有文件，解压后放在一个你找得到的位置（例如“下载”文件夹）。

2.  **打开终端 (Terminal)**:
    - 你可以在“应用程序” -> “实用工具”里找到它。

3.  **进入项目目录**:
    - 使用 `cd` 命令进入你解压后的文件夹。例如：
    ```bash
    cd ~/Downloads/translate  # 请替换成你的实际路径
    ```

4.  **创建并激活虚拟环境** (推荐):
    ```bash
    # 创建虚拟环境
    python3 -m venv venv

    # 激活虚拟环境
    source venv/bin/activate
    ```
    *成功后，你会在命令行前面看到 `(venv)` 字样。*

5.  **安装依赖库**:
    ```bash
    pip3 install -r requirements.txt
    ```

6.  **运行程序**:
    ```bash
    streamlit run app.py
    ```
    *同样，它会自动在你的浏览器中打开程序界面。*

## 🔧 如何新增或修改功能？

如果你想对这个工具进行二次开发，可以从以下几个方面入手：

#### 1. 修改提示词 (Prompt)

最简单的定制方式就是修改 AI 的指令。

- **位置**: [`app.py`](app.py) 文件的第 `267` 行和 `268` 行。
- **修改**:
    - `trans_prompt`: 控制翻译风格的提示词。你可以改成“翻译成日文，口语化风格”。
    - `qa_prompt`: 控制 QA 质量检查的标准。你可以增加一些你们团队特有的规则，例如“检查所有数字是否为半角”。

#### 2. 调整核心逻辑

代码的核心逻辑主要在 `AIAgent` 类中。

- **文件**: [`app.py`](app.py)
- **`run_translation` 函数**:
    - 这里负责调用大模型进行翻译。如果你想增加第三个翻译版本（例如“技术风格”），可以模仿现有结构，修改返回的 JSON 格式。
- **`run_review` 函数**:
    - 这里负责让 AI 评审版本。你可以修改这里的提示词，让它基于不同的标准来做决策。
- **`run_qa_check` 函数**:
    - 这里是 QA 环节，你可以修改提示词以适应更复杂的质检需求。

#### 3. 增加新的导出格式

如果你想增加导出为 JSON 或 CSV 格式：

1.  在 `FileParser` 类中增加一个新的静态方法，例如 `generate_json(text)`。
2.  在 [`app.py`](app.py) 的界面代码部分（大约 `500` 行之后），模仿 `st.download_button` 的写法，增加一个新的下载按钮，并调用你刚刚创建的函数。

希望这份指南能帮助你快速上手！
